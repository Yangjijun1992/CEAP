# μ子 S1 Afterpulse 随机耦合本底大规模模拟分析报告

> 场景：RELICS 类探测器，μ子在液氙中沉积 50 MeV → 391,000 PE 快闪 S1（100 ns），
> 56 只 PMT 均匀接收（每只 ~6,982 PE），全部 PMT APP = 5%（LV2358 PDF，50 ns 时间 bin）。
> **μ子在探测器中的事例率：1.49 Hz**（通量 47.5 Hz/m² × 有效面积 0.0314 m²）
> **模拟 μ子次数：100,000 次**（约 8.5 亿 afterpulse 事件）
> 日期：2026-08-17

**全部 1 μs 窗总 PE 分布**（log-log，78 窗口/μ子 × 100k μ子 = 790 万窗）：

| 统计量 | 数值 |

| 窗内 PE ∈ [120,240]（假信号） | **992,039（12.56%）** |
| 窗内 PE > 240 | 5,433,517（68.78%） |

- 蓝柱：全部 1 μs 窗总 PE 分布；红色竖线标注 **120 PE（下界）/ 240 PE（上界）**，红色阴影为信号窗
- 红柱叠加：落在信号窗 [120,240] 内的假信号谱
- **图上标注三档统计**：<120（18.66%）、信号窗内（12.56%）、>240（68.78%）

**物理结论**：绝大多数窗（68.78%）因 S1 后 afterpulse 电荷密集而 >240 PE 饱和，只有电荷衰减到
中等水平（12.56%）才落入 CEvNS 阈值窗成为假信号，另有 18.66% 窗 <120 PE（未达低阈值）。

## 4.1 线性轴对比与幂律拟合（`fake_signal_energy_compare.png`）

**统一线性轴**（x=1 μs 窗总 PE、y=dN/dPE 每 PE 计数），将所有窗能谱与假信号能谱画到同一坐标系对比：

- 蓝线：所有窗的 dN/dPE 谱（完整）
- 红线：假信号 dN/dPE（仅 [120,240] 段）——**与所有窗谱在该区间完全重合**（假信号本就是所有窗谱中落在 [120,240] 的那一部分）
- 绿虚线：幂律拟合 dN/dPE = A·PE^(-α)

**幂律拟合结果**（全谱 [127, 9464] PE）：

```
dN/dPE ∝ PE^(-0.966)   (A ≈ 9.95×10⁵)
```

即能谱近似 **1/PE**（α≈1）。物理来源：窗均匀分布在时间轴（50 ns 步进）上，而 afterpulse 电荷密度随 Δt 近似指数衰减，二者组合给出 dN/dW ∝ 1/W。这也解释了 log-log 图上所有窗谱"持平"的现象——1/PE 幂律在 log-log 坐标下纵轴 dN/dlogPE = dN/dPE×PE = 常数。

> 附注：分能段拟合显示轻微曲率（低能 [120,800] α≈1.25，高能 [800,10000] α≈0.72），源于 afterpulse 离子峰结构与窗口积分的时间形状，整体仍近似 1/PE。

![线性轴对比与幂律拟合](../output/muon_s1_100k/fake_signal_energy_compare.png)

## 7. 关键物理结论

1. **假信号率仍显著**：1.49 Hz μ子率下，afterpulse 随机耦合在 1 μs CEvNS 信号窗内
   产生 **14.80 Hz** 的假信号——仍远超物理信号率，**是主导性本底**。

2. **假信号不可忽略性**：每 μ子产生 ~9.9 个假信号；μ子事例率每增加 1 Hz，
   假信号率增加 ~9.9 Hz。即便 μ子率降至 0.01 Hz（深地下），仍有 ~0.10 Hz 假信号。

3. **能谱分档结论**：790 万窗中 68.78% 因电荷饱和 >240 PE、12.56% 落入信号窗成为
   假信号、18.66% <120 PE —— 假信号是 afterpulse 本底衰减穿过 [120,240] 阈值窗的
   那一小段时间切片。

4. **死区建议（再次强化）**：afterpulse 主要分布在 S1 后 0–5 μs，必须将死区
   设为 **S1 后 ≥ 5 μs**（`dead_zone.s1_after_ns`），否则这 14.80 Hz 假信号
   会完全淹没 CEvNS 窗口。

5. **收集效率灵敏度**：CE 从 90% 降到 46%（有效光产额 15.3→7.82 PE/keV）使
   S1 从 765k 降至 391k PE，假信号率从 17.46 降至 14.80 Hz —— 每 μ子假信号数
   从 11.71 降至 9.92（假信号数随 S1 近似线性，但非完全线性因为电荷密度跨阈值窗
   窗口的平衡点改变）。
