> 场景：RELICS 类探测器，μ 子在液氙中沉积 120 MeV，100 ns 内产生 1,000,000 PE
> 的快闪 S1 信号；56 只 PMT 均匀接收；全部 PMT APP = 5%。
> 分析窗口：S1 后 [100 ns, 5 μs]；信号符合窗口：1 μs。
> 日期：2026-08-14

## 3. 1 μs 窗口内随机符合事例率

扫描方式：1 μs 滑动窗口，50 ns 步进，覆盖 [100 ns, 5 μs]，每 μ 子 78 个窗口。

| 指标 | 数值 |
|------|------|
| 1 μs 窗内平均 PE | **7,769 PE** |
| 1 μs 窗内 p99 PE | 38,859 PE |
| 窗内总 PE ≥ 120 PE 占比 | **99.85%** |
| 窗内总 PE ∈ [120, 240] 占比（CEvNS 阈值窗命中） | **12.0%** |
| **每 μ 子假信号数**（1 μs 窗∈[120,240] PE） | **9.36 ± 1.86 个** |
| **假信号率**（× μ 子率 R_mu） | **R_mu × 9.36 Hz** |

### 本底率换算示例

| μ 子率 R_mu | 假信号率 |
|-------------|----------|
| 0.01 Hz（100 s 一个 μ 子） | 0.094 Hz |
| 0.1 Hz（10 s 一个 μ 子） | 0.94 Hz |
| 1 Hz（1 s 一个 μ 子） | 9.4 Hz |

## 4. 关键物理结论

1. **afterpulse 电荷巨大**：1M PE 主脉冲 × 5% APP 在 5 μs 内产生约 **5.2 万 PE**
   afterpulse 电荷，不可忽略。
2. **时间高度集中**：约 88% 的 afterpulse 电荷落在前 2 μs，S1 后紧邻的 1 μs 窗
   平均约 7,800 PE —— **远超任何信号阈值**（CEvNS 120–240 PE）。
3. **假信号率非线性放大**：每 μ 子产生约 **9.4 个**落入 CEvNS 阈值窗的假信号；
   若 μ 子率较高（地下 ~0.01 Hz/m² 量级需按探测器面积折合），这部分随机耦合
   本底会非常显著。
4. **死区建议**：死区排除必须覆盖 S1 后至少 **2–5 μs**（框架
   `dead_zone.s1_after_ns` 可配），否则 afterpulse 本底会完全淹没 CEvNS 窗口。

## 5. 模拟实现与复用

分析脚本：`src/ceap/tools/muon_s1_afterpulse_analysis.py`

```
主要参数 (模块顶部常量):
  N_PMT = 56
  MAIN_PE_TOTAL = 1_000_000
  T_WIN_MIN_NS = 100.0    # 分析窗口下界
  T_WIN_MAX_NS = 5_000.0  # 分析窗口上界
  WINDOW_US = 1.0         # 信号符合窗口
  THR_MIN_PE / THR_MAX_PE = 120 / 240  # CEvNS 阈值
  N_MUONS = 200           # 统计 μ 子数
```

PDF 数据：`data/app_pdf_LV2358.npz`（APP≈5.3%，代表 5% 情形）

输出文件：
- `output/muon_s1/muon_s1_afterpulse_analysis.png`（4 面板：电荷分布 / 时间分布 / 1μs窗PE分布 / 窗内电荷vs位置）
- `output/muon_s1/muon_s1_afterpulse_summary.json`（结构化数值）
